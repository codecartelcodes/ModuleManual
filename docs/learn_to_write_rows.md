# Learn How to Write Rows

Each row in the Manual represents a **phase, stage, or task** and uses the following columns:

- Task  
- Details  
- Link  
- Project  
- Group  
- Deadline  
- Notes  
- Owner  

Each row should clearly answer: **who, what, when, where, how, and why**.

---

## Writing Guidelines

- Keep sentences **short and precise**  
- Avoid sentence wrapping to maintain clean printed formatting  
- Do not use “you” or “your”  
- Write for a **manager unfamiliar with the concepts**  
- Ensure clarity, completeness, and consistency  

---

## Column Instructions

### TASK

- Describe the task at a **high level**  
- Include relevant **jargon** to shorten phrasing  
- Use terminology that reinforces domain knowledge  

---

### DETAILS

#### WHAT

- **Phase / Stage rows:** Define the jargon used  
- **Task rows:** Describe what appears on the screen  

#### HOW

- **Phase / Stage rows:** Explain the overall process  
- **Task rows:** Provide exact execution steps (command-style)  

#### WHY

- **Phase / Stage rows:** Explain the purpose of the stage  
- **Task rows:** Justify the method and its effectiveness  

---

### LINK

- Provide a reference to:
  - Google Docs  
  - Websites  
  - Online resources  
  - Videos  

---

### GROUP

- Used to organize and filter related rows  
- Example:
  - `leads` → filters all lead generation activities  

---

### DEADLINE

- Multiple stages may be completed per day  
- Each stage should take **no more than one day**  
- Estimate deadlines based on completing **1–2 stages per day**  
- Use stage count to define:
  - Project velocity  
  - Overall timeline  

---

### NOTES

- Capture updates, changes, or additional context  
- Maintain as a **living record** of task-related information  

---

### OWNER

- Specify the individual responsible for completing the task
