# How to Adjust Row Height to Fit the Data

1. Select the first row that needs adjusting  
2. Hold the **Shift** key and use the **down arrow** to highlight additional rows  
3. Right-click on the highlighted rows  
4. Select **Resize Rows**  
5. Choose **Fit to Data**  
6. Click **OK**

---

## Remove Extra Whitespace in Cells

1. Select the rows (as described above)  
2. Click **Data** in the menu  
3. Select **Trim whitespace**
