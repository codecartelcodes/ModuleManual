# SuiteCRM Access & Permissions Guide

---

## WHAT

**What is accessibility?**  
Accessibility refers to which modules and features a user can access within SuiteCRM.

**What are permissions?**  
Permissions define what actions a user can perform within those modules (e.g., view, edit, delete, export).

---

## WHERE

- In the upper-right corner of the SuiteCRM dashboard, locate the username under the profile icon  
- Click the username  
- Navigate to: **Admin → Role Management**  
- Select the role name to access the **role matrix**

---

## HOW

### Configure Access

- Click **Access** and select **Disabled** from the dropdown menu

### Restrict High-Level Actions

Set the following to **None**:
- Delete  
- Export  
- Import  
- Mass Update  

### Limit Standard Actions

Set the following to **Owner**:
- Edit  
- List  
- View  

### Enable Required Modules

Set **Access = Enabled** for:

- Calls  
- Calls Reschedule  
- Campaigns  
- Email - Templates  
- Email Marketing  
- Emails  
- Knowledge Base  
- Leads  
- Meetings  
- Opportunities  
- Outbound Email Accounts  
- Reports  
- Survey Question Options  
- Survey Question Responses  
- Survey Questions  
- Survey Responses  
- Surveys  
- Targets  
- Targets - Lists  
- WorkFlow  

### Final Step

- Click **SAVE** to apply changes

---

## WHY

- Protect data if a team member (e.g., Motivator) leaves  
- Maintain data security and integrity  
- Simplify system usage by limiting unnecessary access
