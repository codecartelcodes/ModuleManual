# How to Use the Filter Functionality

The Manual is a **project management system built into a Google Sheet**.  

Unlike most project management tools (Trello, Microsoft Project, Redline) that hide task details behind multiple clicks, the Manual shows **all task details by default**. The **filter functionality** is used to hide rows based on column values, allowing you to focus on key information.

The sheet is **designed to be printable**, so everyone can work on paper if desired. The sequencing ensures tasks are completed from **top to bottom**, and dependencies between tasks are easy to see.

---

## Filter Funnel vs. Filter View

- **Filter Funnel** – The icon at the top of a column that filters the data for everyone viewing the sheet.  
- **Filter View Selector** – The small down arrow next to the funnel, which allows you to create personal filter views that **only you see**.

---

## Using the Filter View Selector

1. Click the small down arrow (the **Filter View Selector**).  
2. Click **"phases"** to show only project phases.  
3. Click **"stages"** to show phases and stages.  
4. Click the Filter View selector again and select **"None"** to see all tasks.  
5. Click **"Learn More"** to access videos and tutorials on filter usage and creating filter views.

---

## Using the Filter Funnel

1. Click the **top of the column** to highlight it.  
2. Click the **Filter Funnel** icon; a down arrow appears in the first row of that column.  
3. Click **"Clear"** to deselect all options.  
4. Select the values you want to display and click **"OK"**.  
5. Click the Filter Funnel again to turn off the filter and show all rows.

---

## Caution

- Using the **Filter Funnel** affects **all users**; they will see the filtered sheet.  
- Using the **Filter View** affects **only your view** of the sheet.

---

## Extra Tips

- Filter by your **name** or key team members to display only tasks they are responsible for.  
- Create a **Filter View for each team member**.  
  - Include tasks they own **and** relevant phases and stages.
